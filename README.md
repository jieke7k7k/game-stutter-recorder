# 游戏卡顿记录程序（简化版第一版）

这是一个能在你玩游戏时记录的程序，不是只有分析旧日志的工具。

## 你要准备的东西（都免费、都官方）

1. **Python**：去 python.org 下载安装，安装时勾选 `Add python to PATH`。
   装完双击 `start.bat`，能打开程序窗口就说明 Python 没问题。
2. **PresentMon**：去官方仓库下载
   https://github.com/GameTechDev/PresentMon
   把里面的 `PresentMon.exe` 解压到这个程序同一文件夹里。
   程序不会替你从不明网站下载 exe，找不到它时会直接告诉你。

## 怎么用（就 4 步）

1. 先打开游戏，进入能玩的状态。
2. 双击 `start.bat` 打开记录程序，在“游戏 exe”里填游戏进程名
   （不知道名字就点“刷新进程”，在下拉里找，一般以 `.exe` 结尾）。
3. 点“开始记录”，回到游戏正常打，打到卡顿的地方也别停。
4. 打完回到记录程序，点“停止并分析”，报告会自动在浏览器里打开，
   最上面一句话就是结论，下面是当时的数字。

记录保存在程序旁边的 `Records\日期-时间-游戏名\` 里，
里面有 `frames.csv`（逐帧数据）、`sensors.csv`（每秒的系统数据）、`报告.html`。

## 这个版本能做什么、不能做什么

能做：
- 逐帧记录帧时间、GPU Busy，带时间戳。
- 每秒记录 CPU 占用、内存占用；有 nvidia-smi 时再记 GPU 温度、功耗、频率、占用、显存。
- 停后自动分析，给一句中文结论加证据。

还做不到（先说清楚）：
- CPU 温度：Windows 不装传感器驱动读不到，第一版不承诺这一项。
- 全局热键开始/停止：第一版用窗口按钮，停的时候 Alt-Tab 回到程序点停止。
- 自动识别所有游戏：要你手动选一次游戏 exe 名。
- 结论是“最可能”，不是百分之百；卡顿可能几个原因叠在一起。

## 如果出问题

- 提示找不到 PresentMon：按上面第 2 步，把 exe 放到程序旁边。
- 提示 frames.csv 是空的：先确认游戏 exe 名没写错，游戏在记录时确实在运行，
  记录时间别太短（至少打一小段）。
- 程序打不开：先确认 Python 装好了并且勾了 PATH，把报错截图发给我。

## 旧日志也能分析

不用录制、只想分析一个已有的 CSV，可以这样：

```
python recorder.py --analyze 旧文件.csv
```

会在同目录生成 `报告.html`。没有时间戳的旧文件只能看个大概，报告里会明说。
