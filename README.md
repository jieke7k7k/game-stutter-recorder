# 游戏卡顿记录 向导版（v1.2.0）

这是 v1.1.0 Qt 版的升级版：界面改成三步向导，记录和分析逻辑没有变，全部复用 `recorder.py`。

## 三步怎么用

1. **先打开你的游戏**：程序会自动找到正在运行的游戏，优先猜你当前前台窗口的游戏（只取进程名，不读窗口标题、不注入游戏）。猜错了手动改一下就行，手动输入永远不会被刷新覆盖。
2. **点开始记录**：去玩，卡顿不用停，继续玩一会儿再回来。
3. **点停止并分析**：报告自动打开，第一句话就是“最可能”的结论，证据和详情在后面。

## 这一版和以前不一样的地方

- **就一个文件**：下载 `GameStutterRecorder.exe` 就能用，PresentMon 2.6.0 已经打在里面了，不用单独下载、不用放同一文件夹。
- **F9 开始/停止**：在游戏里按 F9 就能开始或停止，不用切出游戏。F9 被别的程序占了时，界面会写清楚，按钮照常能用。
- **深色模式**：启动时跟随系统，右上角可以手动切换，手动选择会记住；生成的报告也跟随系统深色。
- **设置里才有 PresentMon 路径**：平时不用管，程序先用 exe 旁边的、再用内置的、最后用设置里选的。

## 运行

- 打包后：双击 `GameStutterRecorder.exe`，不需要装 Python。
- 源码运行：`pip install PySide6`，然后 `python app_wizard.py`。
- 只分析旧文件（不用界面）：`python app_wizard.py --analyze 旧文件.csv`。

## 还是要说的限制（和以前一样，不藏着）

- 程序是未签名的，Windows 第一次打开可能会弹 SmartScreen，点“更多信息”再点“仍要运行”。
- CPU 温度在 Windows 下不装驱动读不到，这一版不承诺，只用 CPU 占用、内存、GPU 温度功耗判断。
- 结论永远是“最可能”，不是百分之百。
- 程序不注入游戏，PresentMon 是 ETW 外部采集。

## PresentMon 是谁的

PresentMon 是 Intel 的官方开源工具，官方仓库是 https://github.com/GameTechDev/PresentMon ，许可证以官方仓库为准。本程序只是调用它采集逐帧数据，采集部分的代码不是本程序写的。
